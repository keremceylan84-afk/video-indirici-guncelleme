# Video İndirici: güncellemeler

Bu depoda yalnızca **Video İndirici** uygulamasının kurulum dosyaları bulunur (kaynak kod özel depoda).
Uygulama açılışta [en son sürümün](../../releases/latest) `surum.json` dosyasına bakar ve yeni sürümü kendisi indirir.

| Dosya | Cihaz |
|---|---|
| `video-indirici-arm64-v8a.apk` | Android telefon/tablet (çoğu cihaz) |
| `video-indirici-armeabi-v7a.apk` | Eski 32 bit Android cihazlar |
| `video-indirici-x86_64.apk` | Android emülatör |
| `video-indirici-windows.zip` | Windows 10/11 |

İlk kurulum: Android'de APK'yı açıp kurun. Windows'ta zip'i açıp `video_indirici.exe`'yi çalıştırın.
